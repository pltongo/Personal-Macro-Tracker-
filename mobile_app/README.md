# MacroTracker Mobile (iOS & Android)

Native cross-platform mobile application powered by **React Native** and **Expo**.

## How to Run on Your Phone

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Expo development server:
   ```bash
   npx expo start
   ```

3. **Open on your device**:
   - **iOS**: Scan the QR code using your iPhone Camera app to open in **Expo Go**.
   - **Android**: Scan the QR code using the **Expo Go** app from Google Play Store.

4. In the app's **Settings** tab, set the backend server URL to your computer's local IP (e.g. `http://192.168.1.50:8000`) or your hosted cloud domain.
